# Security policy

This project is intended to run locally on loopback interfaces. Do not expose the Gradio, HTTP, or WebSocket services to an untrusted network.

Report security or privacy problems privately to the repository owner. Do not include credentials, voice recordings, transcripts, or other personal data in a public issue.

Before reporting a problem, remove sensitive values from logs and verify that the reproduction does not include a real person's voice unless they have explicitly consented to its use.
